# jonathanpay.github.io

Personal site for [jonathanpay.com](https://jonathanpay.com), built with Jekyll for GitHub Pages.

## WordPress import

The migration script at `scripts/import_wordpress.py` imports posts, pages, drafts, and media from `~/Downloads/jonathanpay.WordPress.2026-07-03.xml`. Comments and WordPress.com internal records are not imported.
