# Archive

Retired pages kept for reference. Jekyll skips folders that start with an underscore, so nothing here is published. The tests still run against these files.

- `pilots/email-maturity-assessment/`: the GitHub pilot of the Email Maturity Assessment, replaced by https://holisticemailacademy.com/email-maturity-assessment/.
- `workshops/london-forum/`: the London Forum workshop assessment, room dashboard, slides and collector.

The old public addresses (`/pilots/email-maturity-assessment/`, `/workshops/london-forum/email-maturity-assessment/`, `/mon/` and `/tue/`) redirect to the Academy assessment. The archived pages load fonts and course data from `/email-tools/assets/`, which is no longer published either, so they only render when served from the repository root (as the browser tests do).
