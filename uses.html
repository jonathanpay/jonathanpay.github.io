Uses /

The tools I use for work and everything adjacent to it. Updated when something changes. Last updated October 2026. Looking for the tools I've built? Those are on the tools page.

Hardware /

My main machine is a 2021 M1 iMac, which still feels fast enough that I have no reason to replace it. I use a reMarkable 2 for reading, note-taking, and getting thoughts down without a screen full of notifications competing for attention. My phone is an iPhone SE (3rd generation), because I don't need my phone to be exciting.

Writing /

I draft and develop almost everything in Obsidian, which serves as my second brain. Flat file structure, YAML front matter, wikilinks, and a level of organisational ambition that occasionally outpaces my organisational discipline. Course content, blog drafts, theology notes, and RPG session prep all live side by side.

For prose editing I use HemingwayApp to catch overwriting, and Writhm for voice and readability checking. Both are useful correctives when a draft has spent too long in my own head.

Building /

I vibe-code the tools on this site with Claude, working through GitHub. I describe what I want, Claude writes the code, and the change goes up as a pull request that I read before it merges.

This site is Jekyll on GitHub Pages, using the default setup. Every page, post, and tool is a file in a repository, which is why I can reshape it however I like. It's where jonathanpay.com is heading, though I haven't moved across properly yet.

AI and automation /

Claude (Anthropic) is my primary AI tool, used for content drafting, research, structural thinking, and building out workflows. I use Cowork alongside it for desktop automation: content pipelines that take a draft from Google Drive through to LinkedIn, Substack, and Bluesky without manual reposting.

I also use ChatGPT and DeepSeek, with all three running in Hermes Agent.

I've tried local models too, through Ollama or LM Studio with Gemma 4. Keeping processing on-device appeals when privacy matters. I've only experimented so far and haven't put one into active work.

Zapier connects the backend systems: ThriveCart purchases trigger Teachery enrolments, which trigger Mailchimp sequences, which trigger follow-up flows. It's more plumbing than glamour, but it works.

Courses and sites /

The Holistic Email Academy runs on Teachery for course delivery, ThriveCart for checkout, and Mailchimp for email automation and student communications. All the sites (jonathanpay.com, holisticemailmarketing.com, holisticemailacademy.com) currently run on WordPress with Yoast SEO.

Video /

I edit video in Descript. It suits the work I do (course content, talking heads, short branded intros and outros) without the overhead of a full editing suite. The transcript-first editing model suits how I think about content anyway.

The bridge layer /

Google Drive sits underneath most of this as the connective tissue between tools. Cowork reads from and writes to Drive, Zapier pulls from it, and it's the staging ground for content before it goes anywhere public.

Games and screens /

This section is more library than daily use. I haven't played an RPG in years, but the accounts and PDFs are all still there.

The pandemic pushed my RPG playing online, so I have accounts on D&D Beyond, Foundry VTT, Roll20, and Alchemy VTT. There's a Demiplane account too, with some Free League content on it. Free League looks to be building its own platform, but I'm not buying the same books again for another service. I'll stick with the PDFs and platforms I already have. A lot of those PDFs came from DriveThruRPG.

The Xbox One S still has a selection of games on it that I haven't touched in a long time. For watching, I have Sky plus Disney, Netflix, HBO, and Amazon, and a DVD and Blu-ray collection that is smaller than it used to be.
