Mission Board

An unofficial mission and travel generator for Coriolis: The Third Horizon

No data file loaded, so the board shows rolls and table numbers rather than results.

Post jobs

Each line can be rerolled or picked by hand. Accepting a job moves it to the Log and sets up the trip on the Travel tab.

Icon deck

The ship and crew

Plot a route

Takes the fewest jumps on the map, with a day's transit through each system in between. Replaces the legs below.

Add a leg

Rolling fills every leg. Each result can be rerolled after.

    Generate a world

    Modifiers chain as you go: atmosphere moves temperature and geosphere, size moves population, population moves the spaceport. Rerolling a line reworks the lines below it.

    The log

    Jobs you accept, voyages and worlds you save. Copy any entry as Markdown for your notes.
