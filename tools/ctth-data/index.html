Table data /

The Third Horizon tools roll the dice and chain the modifiers. The text on the tables comes from you.

The Mission Board, System and Coriolis Sheets tools carry dice, table numbers, place names and the numbers that drive the mechanics. They don't carry the books' table entries, because those belong to Free League. So that a roll can say "Judicator" instead of "Read Table 19, result 31", you give each tool a data file with the entries from your own copy of the books.

This page explains the file and gives you a template to fill in. Nothing you load is uploaded anywhere. It sits in your browser's storage and nobody else can see it.

Download the template (JSON)

What's in the template

Fifty tables, each with its dice and its roll ranges already set out, and every result left blank. You fill in the names. Roll ranges (lo and hi) are the structure, so leave them as they are unless your book's ranges differ.

"w.size": {
  "dice": "2D6",
  "rows": [
    { "lo": 2, "hi": 2, "n": "", "d": "" },
    { "lo": 3, "hi": 3, "n": "", "d": "" }
  ]
}
  • n is the result as the table names it: the line that appears when you roll.
  • d is optional. Use it for a longer note you want to see under the result. Leave it out, or leave it empty, if you don't want one.
  • A roll that falls outside the table reads as the first or last row, so modified rolls need no extra rows.

Filling it in

  1. Open the template in any text editor. A plain editor is safest. Word processors swap in curly quotes, which break JSON.
  2. Find a table by its id, such as employer.agents or w.atmosphere, and type each result between the quotes after "n":.
  3. Keep the quotes, commas and braces. If a result contains a quotation mark, write it as \".
  4. Save the file. Check it in a JSON checker if you like. The tool will tell you if it can't read it.

Do a table at a time. A table whose results are all blank is ignored, and the tool falls back to telling you which table and result to read. Once a table has any entries, though, every row in it is used as written, so fill in all of its rows or none. Empty rows in a half-done table show up as empty results.

Two tables arrive pre-filled. mission.type holds the numbers that drive the mission generator (destination, complications, reward dice and difficulty), and w.spaceport holds the modifiers for each port. Those aren't table text, so leave them alone.

Loading it

ToolWhere
Mission BoardData tab, Import a data file
SystemData tab, Import a data file
Coriolis SheetsGeneration tables, Manage table data, Import tables

The template uses the Mission Board format, which all three read. The Mission Board and System share one stored file. Coriolis Sheets keeps its own copy, so import the file there too if you want generation on the sheets. An import replaces what you had before, so keep your filled-in file somewhere safe.

Where it lives

Each tool stores the file in localStorage in your browser. It stays across visits and restarts. It's gone if you clear site data, use a private window, or switch browser or device. Keep your JSON file as the master copy and import it again whenever you need to.
