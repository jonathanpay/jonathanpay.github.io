# Tests

    node --test "tests/*.test.mjs"

These cover the pure logic of the tabletop tools in `tools/`. This folder is excluded from the published site in `_config.yml`.

The email tools and the Email Maturity Assessment, and their tests, moved to the private `jonathanpay/hea-email-tools` repository in November 2026.
