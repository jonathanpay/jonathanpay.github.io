## Outstanding problem: GitHub Pages deployment failing

All PRs (#4, #5, #6, #7) have triggered the same class of failure:

```
Failed to download archive 'https://codeload.github.com/actions/<action-name>/tar.gz/<sha>' after 1 attempts.
An action could not be found at the URI 'https://codeload.github.com/actions/<action-name>/tar.gz/<sha>'
Internal server error. Correlation ID: <id>
```

This is a **GitHub infrastructure issue** — `codeload.github.com` is failing to serve action archives to this runner. It is not a code problem. The error occurs even with different actions (first `jekyll-build-pages`, then `upload-pages-artifact`).

### Things already tried

| Attempt | Result |

| `.nojekyll` file | Merged, didn't stop failure |
| Custom `deploy.yml` bypassing Jekyll | Still fails — different action, same download error |

### Possible next steps to try

1. **Re-run the failed workflow manually** from the Actions tab — transient infrastructure errors sometimes clear on retry
2. **Check GitHub Status** at githubstatus.com for any ongoing Pages/Actions incident
3. **Contact GitHub Support** with a Correlation ID (e.g. `295c5728-91b0-4fc3-97a9-4c4871573a09`) — this points to a backend issue on their end
4. **Wait** — these transient `codeload.github.com` failures often self-resolve within hours
